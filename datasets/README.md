# Datasets

Složka s různými datasety otázek.

- `template.json` stažený z originálního projetku

## Nabožko

Dataset otázek pro hodinu nábožentství.

- `nabozko\advent.json` - adventní otázky
- `nabozko\bible_2.json` - otázky na Bibli připravené jako aktivity, tj. součástí je kreslení, pantomima, hledání citátu z Bible, ...
- `nabozko\bible.json` - otázky na Bibli připravené jako aktivity, tj. součástí je kreslení, pantomima, hledání citátu z Bible, ...
- `nabozko\krizova-cesta.json` - otázky z příběhu křížové cesty
- `nabozko\papezske.json` - otázky o papežském úřadě, Vatikánu, papeži Františku v době jeho úmrtí
- `nabozko\popelecni-streda-2024.json` - otázky týkající se popeleční středy
- `nabozko\popelecni-streda.json` - otázky týkající se popeleční středy s úkoly
- `nabozko\sumare-2023.json` - otázky shrnující oblati probrané za rok 2023
